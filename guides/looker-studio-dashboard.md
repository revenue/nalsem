# 날셈 대시보드 만들기 (Looker Studio)

GA4 속성 `G-7V7PNG5749` 의 데이터를 Looker Studio 보고서 한 개(6페이지)로 봅니다. 순서대로 따라 하면 약 60~90분 걸립니다.

- 비용: 무료
- 공개 범위: 본인 Google 계정 안에서만 보입니다. **공유 버튼으로 "링크가 있는 모든 사용자"를 켜지 마세요.**
- 개발 지식은 필요 없습니다. 모든 작업은 브라우저 클릭입니다.

> 이 문서는 사이트에 게시되지 않습니다(`docs/` 폴더 밖). GA 수치는 대시보드 안에만 있고 이 문서에는 없습니다.

## 0단계. GA4 에서 먼저 할 일 (15분)

대시보드가 계산기 이름·클릭 영역을 보여 주려면, GA4 가 그 값을 "측정기준"으로 알고 있어야 합니다.

### 0-1. 맞춤 측정기준 6개 등록

GA4 → 왼쪽 아래 **관리(톱니바퀴)** → 속성 열 **데이터 표시 → 맞춤 정의** → **맞춤 측정기준 만들기**. 아래 6개를 하나씩 만듭니다. **범위는 모두 "이벤트"** 입니다.

| 측정기준 이름 (보고서에 보이는 이름) | 이벤트 매개변수 (정확히 이대로) | 설명 |
|---|---|---|
| 계산기 | `calculator` | 결과를 본 계산기 |
| 클릭 영역 | `area` | 홈 연동 카드·목록·함께 보기·검색·메뉴 등 |
| 출발 페이지 | `from` | 클릭한 페이지 |
| 도착 계산기 | `item_id` | 클릭해서 간 계산기 |
| 사이트 검색어 | `search_term` | 검색창에서 고른 결과의 검색어 |
| 테마 | `theme` | 다크/라이트 전환 |

- 등록한 **다음 날부터** 값이 쌓입니다. 그 전 데이터에는 "(not set)" 으로 나옵니다.

### 0-2. `calculate` 를 주요 이벤트로 지정

"조회했다"가 아니라 "실제로 계산했다"를 전환으로 보기 위해서입니다.

**관리 → 데이터 표시 → 이벤트** → 목록에서 `calculate` 오른쪽 **별(주요 이벤트로 표시)** 을 켭니다.
- 목록에 `calculate` 가 없으면 아직 한 번도 발생하지 않은 것입니다. 사이트에서 계산기를 한 번 써 보고 몇 시간 뒤 다시 보거나, **주요 이벤트 → 새 주요 이벤트** 에 `calculate` 를 직접 입력하세요.

### 0-3. 데이터 보관 기간 늘리기

**관리 → 데이터 수집 및 수정 → 데이터 보관** → 이벤트 데이터 보관 **14개월** → 저장. (기본 2개월이면 장기 추이를 못 봅니다)

### 0-4. 애드센스 연결 (애드센스 승인 후)

광고 수익 페이지는 애드센스가 **"준비됨"** 이 된 뒤에 연결합니다. 지금은 건너뛰고 6단계에서 다시 합니다.

**관리 → 제품 링크 → AdSense 링크 → 연결** → 게시자 ID `pub-2298882938781262` 선택 → 제출

## 1단계. 보고서 만들기 (5분)

1. GA4 **관리 → 속성 설정 → 속성 세부정보** 에서 **속성 ID**(숫자 9~10자리)를 복사합니다. 측정 ID(G-...)와 다릅니다.
2. 아래 주소의 `속성ID` 자리에 붙여 넣고 브라우저로 엽니다. GA4 가 연결된 빈 보고서가 바로 만들어집니다.
   ```
   https://lookerstudio.google.com/reporting/create?ds.ds0.connector=googleAnalytics&ds.ds0.propertyId=속성ID
   ```
   - 주소가 안 되면: https://lookerstudio.google.com → **빈 보고서** → 데이터 추가 **Google 애널리틱스** → 계정 `suik.me` → 속성 `날셈` → **추가**
3. 왼쪽 위 제목을 **날셈 대시보드** 로 바꿉니다.

## 참고: 사이트가 보내는 이벤트

| 이벤트 | 매개변수 | 언제 |
|---|---|---|
| `page_view` | `content_group` (age/date/home/info) | 페이지 열 때. URL 의 `?` 뒤 입력값은 지우고 보냄 |
| `calculate` | `calculator` | 사용자가 입력해 결과가 바뀔 때 (5초에 1번) |
| `select_content` | `item_id`, `area`, `from`, `search_term` | 사이트 안 링크 클릭 |
| `search_open` / `search_close` | `results` | 검색창 열기/닫기 |
| `share_click` | `calculator` | 공유 버튼 |
| `theme_toggle` | `theme` | 다크/라이트 전환 |

🔴 생년월일·날짜·이름 등 **입력값은 어떤 이벤트에도 들어가지 않습니다.**
